1 · 이미지

지금은 예시 이미지입니다.

2 · 테두리 넣을 영역 선택

펜슬로 칠한 부분 안의 글자·그림만 인식합니다. 붙어 있는 그림을 나눌 때 좋아요. 펜슬을 화면 가까이 대면 브러시 크기가 보여요.

✏️ 애플펜슬로 선택 · ✌️ 두 손가락으로 확대/이동 · 두 손가락 탭 = 되돌리기, 세 손가락 탭 = 다시 실행

3 · 테두리

감도 숫자가 클수록 반투명한 부분(그림자, 흐린 가장자리)은 무시합니다. 두께는 원본 픽셀 기준이에요.

4 · 확정 · 저장

확정하면 테두리가 그림에 합쳐지고, 다른 영역을 다른 두께로 이어서 작업할 수 있어요. 초기화는 처음 올린 그림으로 되돌리고 선택을 지워요. 되돌리기는 선택 작업도 하나씩 되돌려요. (키보드: ⌘/Ctrl+Z)

아래 이미지를 1초 정도 꾹 누르면 메뉴가 떠요. 손을 떼지 말고 메뉴가 나올 때까지 누르세요.
· 사진 앱에 넣기 → Save to Photos (사진 앱에 저장)
· 파일 앱에 넣기 → 위의 파란 저장 버튼을 누르면 파일 앱 › 다운로드에 들어가요. 원하는 폴더로는 파일 앱에서 옮겨 주세요.
다른 메뉴(Copy, Copy Subject)는 쓰지 않아도 돼요.
